# SBMS — Smart Bakery Management System (نظام إدارة المخابز الذكي)

نظام ERP متكامل باللغة العربية (`RTL`) لإدارة المخابز التجارية السودانية، يجمع بين الرقابة المخزنية الصارمة، تتبع الإنتاج اليومي للخبز، إدارة الورديات وتسليم العهد، المبيعات النقدية والآجلة، وإدارة الموردين والعملاء والموظفين والخزينة والتقارير المالية.

---

## المعمارية التقنية

- **الواجهة الأمامية (Frontend):** React 19 + TypeScript + Vite 8 + Tailwind CSS v4 (RTL)، مع تقسيم الكود عبر `React.lazy` و`Suspense` وفصل الحزم الثقيلة (`xlsx`, `jspdf`, `recharts`, `firebase`) وتنظيم صفحات المحاسبة والعمليات في وحدات مستقلة.
- **الخادم الخلفي (Backend):** Express 4 يعمل محلياً عبر `server.ts` على المنفذ `3000` (متوافقاً مع **Node.js 22 Native ESM**) وعلى بيئة **Vercel Serverless** عبر `api/index.ts`، مع تقسيم المسارات والخدمات إلى وحدات متخصصة (`src/server/routes/operations/*`, `src/server/routes/accounting/*`, `src/server/services/*`).
- **قاعدة البيانات (Database):** PostgreSQL (متوافق مع Cloud SQL أو Neon أو Supabase Pooler على المنفذ `6543`) باستخدام **Drizzle ORM** و31 جدولاً علائقياً بأنواع `NUMERIC(14,2)` للمبالغ و`NUMERIC(14,3)` للكميات المخزنية، مع إنفاذ SSL الآمن افتراضياً في الإنتاج واتصال Pool كسول (`lazy`).
- **الدقة المحاسبية والاختبارات:** تنفيذ الحسابات المالية والتقريب (`ROUND_HALF_UP`) عبر مكتبة `decimal.js` داخل وحدة نقية (`src/server/accounting/formulas.ts`) مغطاة باختبارات وحدة آلية عبر `Vitest` (`npm test`).
- **المصادقة والأمان:** تشفير كلمات المرور عبر `scrypt` (`salt` عشوائي 16 بايت)، رموز وصول وتحديث منفصلة (`JWT_SECRET` و`JWT_REFRESH_SECRET` بإلزام طول 32+ حرفاً في الإنتاج)، تدوير رمز التحديث وكشف إعادة الاستخدام، التحقق الصارم من الأدوار (`OWNER` vs `AGENT`) وصلاحيات الوكيل، والتحقق من المدخلات عبر `Zod`.
- **الاستقلالية التشغيلية ومدير الحزم:** التطبيق خالٍ تماماً من أي استدعاءات أو واجهات ذكاء اصطناعي، وتعتمد عملياته على المعاملات الذرية (`db.transaction`) وأقفال التزامن (`pg_advisory_xact_lock`)، مع إدارة الاعتماديات عبر `bun` (`bun.lock`).

## الوحدات الرئيسية

1. **بوابة المالك (Owner Portal):**
   - لوحة تحكم مالية حية (الإيرادات، النقد المحصل، تكلفة البضاعة المباعة، صافي الربح التقديري، رصيد الخزينة، ذمم الموردين والعملاء، قيمة المخزون).
   - **الموردون والمشتريات:** فواتير متعددة الأصناف (`مسودة` / `مرحّلة` / `ملغاة`)، مدفوعات جزئية وكلية، قيود عكسية، إيصالات سداد، وكشف حساب تفصيلي قابل للطباعة.
   - **المستودع والمخزون:** إدارة المواد الخام والتغليف، تشغيلات الصلاحية وصرف `FEFO/FIFO`، متوسط التكلفة المرجح، وتنبيهات نقص الحد الأدنى وقرب انتهاء الصلاحية.
   - **الإنتاج والوصفات:** وصفات معيارية متعددة، تسجيل الدفعات والتالف، وخصم المكونات ذرياً.
   - **المبيعات ومطابقة الخبز:** فصل المبيعات النقدية والآجلة عن معاملات المرتجعات والتالف والتسويات المعتمدة (`bread_movements`).
   - **الوكلاء والورديات وتسليم العهد:** فتح وإغلاق الورديات، تقارير ختامية، اعتماد تسليم العهد (`shift_handovers`)، وإدارة الصلاحيات.
   - **المالية والعملاء والموظفون:** 8 فئات للمصروفات مع المرفقات، دفتر الخزينة الحي، العملاء الآجلين والتسويات، الموظفون والحضور والرواتب، و13 تقريراً مالياً مع تصدير Excel (`.xlsx`) وPDF والطباعة الرسمية.
2. **بوابة الوكيل (Agent Workspace):**
   - واجهة تشغيلية مقيدة بصلاحيات الدور لتسجيل الإنتاج، المبيعات، المصروفات، وفتح/إغلاق الوردية الخاصة بالوكيل فقط مع طابور مزامنة محلي عند انقطاع الشبكة (`clientTxId`).
